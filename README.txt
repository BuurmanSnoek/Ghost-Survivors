---===========--- GHOST SURVIVORS ---===========---

1) HOW TO PLAY

Start de game door het programma Ghost_Survivors.py uit te voeren.
Na het bekijken van de opening cinematic kun je de gameplay starten,
door in het hoofdmenu op 'Spel starten' te klikken.
Het spookje is dol op pompoenen, verzamel deze.
Het spookje is bang voor spinnen, heksen en andere griezels, ontwijk deze.
Het spel is voorbij zodra het spookje vijf keer is geraakt.


2) BESTURING

De speler kan de game besturen op drie manieren:
	Via het toetsenbord met WASD
	Via het toetsenbord met de pijltoetsen
	Via een SNES-controller met de D-pad
	Voor menu-navigatie is gebruik van een muis noodzakelijk
